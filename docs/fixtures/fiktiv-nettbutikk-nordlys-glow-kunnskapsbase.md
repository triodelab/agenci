## 1. Merkevare og om oss

**Nordlys Glow** er en norsk nettbutikk (fiktiv) som selger nøye kuraterte hudpleie-, kroppspleie- og sminkeprodukter med fokus på skandinavisk enkelhet, dokumenterte ingredienser og bærekraftig emballasje. **Verdier:** Åpenhet om innhold, ingen dyretesting på egne merkevarer (fiktiv), redusert unødvendig emballasje, og kundeservice som svarer på norsk innen én virkedag.

## 11. Ingrediensforklaringer (ordliste for agent-testing)

- **Niacinamid:** B3-vitamin; ofte brukt for olje kontroll og barrierestøtte.  
- **Hyaluronsyre:** Suger til seg fuktighet; finnes i ulike molekylvekter.  
- **Retinol:** Vitamin A-derivat; kan irritere — gradvis intro.  
- **AHA/BHA:** Sure eksfolianter; AHA vannløselig, BHA oljeløselig (salicylsyre).  
- **SPF:** Sun Protection Factor — måling av UVB-beskyttelse, ikke «timer i sol».  
- **Comedogen:** Tette porer hos noen — ikke universell liste.  
- **Hypoallergen:** Markedsføringsbegrep; garanterer ikke null reaksjon.  
- **Dermatologisk testet:** Kan bety ulike studier — les detaljer fra produsent.  
- **Vegan:** Ingen animalske ingredienser i formel (kan fortsatt inneholde kjemikalier fra petroleumsbaserte kilder).  
- **Cruelty-free:** Ingen dyretesting på ferdig produkt i dette fiktive merket.

## 12. Ofte stilte spørsmål (utvidet)

**Spørsmål:** Kan jeg kombinere retinol og C-vitamin?  
**Svar:** Mange bruker C om morgenen og retinol om kvelden. Samme påføring samme øyeblikk kan irritere — introduer ett og ett produkt.

**Spørsmål:** Hvor lang tid før jeg ser effekt av serum?  
**Svar:** Ofte 4–8 uker for hudfornyelse-produkter, men individuelle variasjoner.

**Spørsmål:** Sender dere til Svalbard?  
**Svar:** Ja, mot tillegg i frakt (fiktivt). Leveringstid 5–10 virkedager.

**Spørsmål:** Mister jeg angrerett om jeg åpner emballasjen?  
**Svar:** Du kan angre på uåpnede varer. Åpnet kosmetikk kan ikke returneres av hygieniske grunner med mindre feil eller mangel.
